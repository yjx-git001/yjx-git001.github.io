00 · QUICKSTART

通用配置步骤

先把 Node.js 和 Git 这两个基础环境准备好。基础配置完成后，再按你的需求选择走 GPT 路线或 Claude 路线。

执行环境

下面的步骤默认都在 Windows 或 macOS 的终端里完成。Windows 推荐使用 PowerShell 或 Windows Terminal；Node.js 和 Git 先装齐，再继续后面的工具安装。

1. 检查 Node.js 与 npm

先运行下面命令，确认本机已经安装 Node.js 和 npm。两条命令都能输出版本号，就说明基础环境正常。

Terminal
NODE.JS CHECK 
node -v
npm -v
如果没有 Node.js

如果上面这条命令没有输出版本号，可以直接在终端里安装，然后重新打开终端再执行 node -v 和 npm -v 检查。

Windows PowerShell / Windows Terminal

推荐先安装 Node.js LTS。Node.js 安装完成后会同时带上 npm，后面安装 Codex CLI 会用到它。

WINDOWS INSTALL 
winget install --id OpenJS.NodeJS.LTS -e --source winget
安装过程中按提示确认即可。安装完成后，关闭当前终端，重新打开 PowerShell，再检查是否生效：
VERIFY 
node -v
npm -v
能看到两个版本号就可以继续。如果 node 可用但 npm 不可用，先重新打开终端；仍不正常再重新安装 Node.js LTS。

如果不习惯命令行，也可以打开 Node.js 官方下载页，选择 LTS 的 Windows Installer，安装选项保持默认并确保加入 PATH。

打开下载页
Terminal

如果还没有 Homebrew，先在终端里安装 Homebrew：

HOMEBREW 
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

然后安装 Node.js：

MACOS INSTALL 
brew install node
安装完成后，重新打开终端，检查是否生效：
VERIFY 
node -v
npm -v

如果还没有 Homebrew，或者更习惯图形界面安装，也可以直接打开 Node.js 官方下载页。

打开下载页

2. 检查 Git

再确认 Git 是否已经可用。后面的 GPT 和 Claude 路线都会依赖 Git 环境。

Terminal
GIT CHECK 
git --version
如果没有 Git

如果这条命令没有输出版本号，可以先安装 Git，然后重新打开终端再执行 git --version 检查。

Windows PowerShell / Windows Terminal

推荐安装 Git for Windows。安装器会同时提供 Git Bash，并让 PowerShell 可以直接使用 git 命令。

WINDOWS INSTALL 
winget install --id Git.Git -e --source winget
安装过程中如果出现选项，第一次使用保持默认即可。安装完成后，关闭当前终端，重新打开 PowerShell，再检查是否生效：
VERIFY 
git --version
第一次正式提交代码前，可以再配置一次提交身份：git config --global user.name "你的名字" 和 git config --global user.email "你的邮箱"。

如果不习惯命令行，也可以直接去 Git 官方下载页下载 Git for Windows，安装时保留默认选项。

下载 Git
Terminal

如果还没有 Homebrew，先在终端里安装 Homebrew：

HOMEBREW 
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

然后安装 Git：

MACOS INSTALL 
brew install git
安装完成后，重新打开终端，检查是否生效：
VERIFY 
git --version

如果更习惯图形界面安装，也可以直接打开 Git 官方下载页获取 macOS 安装包。

打开下载页

01 · GPT / CODEX CLI

GPT（Codex CLI）安装与使用

基础环境准备好后，如果你走 GPT 路线，就在这里安装和使用 Codex CLI。Windows 直接在 PowerShell 里用 npm 全局安装；需要 Linux 原生环境时再使用 WSL2。

Install
Codex CLI 
npm install -g @openai/codex
# or
brew install codex

codex

使用流程

  1. 运行 codex 并完成登录。
  2. 直接输入任务开始使用。
codex --help 可查看全部命令。
Windows PowerShell
Codex CLI 
npm install -g @openai/codex

codex --version

codex

使用流程

  1. 先确认 node -v、npm -v 和 git --version 都能输出版本号。
  2. 在 PowerShell 里执行 npm install -g @openai/codex 全局安装。
  3. 安装完成后直接运行 codex，第一次启动时按提示登录。
Windows 原生可用；只有项目依赖 Linux 工具链、仓库本来就在 WSL2，或原生沙箱不可用时，再切换到 WSL2。
02 · CLAUDE CODE

Claude Code 安装与使用

只保留安装、登录和启动。

Install
Claude Code 
# 推荐：原生安装
curl -fsSL https://claude.ai/install.sh | bash

# 可选：需要 npm 兼容安装时
npm install -g @anthropic-ai/claude-code

# Homebrew
brew install --cask claude-code

claude

使用流程

  1. 优先使用原生安装；只有需要 npm 兼容方式时，再执行 npm install -g @anthropic-ai/claude-code。
  2. 运行 claude 并完成登录。
  3. 直接输入任务开始使用。
原生安装会自动更新；Homebrew 和 npm 安装都需要你自己升级。npm 安装要求 Node.js 18+。
Windows
Claude Code 
# 推荐：原生安装
irm https://claude.ai/install.ps1 | iex

# 可选：需要 npm 兼容安装时
npm install -g @anthropic-ai/claude-code

claude

使用流程

  1. Windows 原生安装前先准备好 Git for Windows。
  2. 优先使用官方原生安装；只有需要 npm 兼容方式时，再执行 npm install -g @anthropic-ai/claude-code。
  3. 安装完成后直接运行 claude。
  4. 登录后直接开始使用。
Windows 原生安装使用 PowerShell 命令；如果走 npm 安装，同样需要先准备好 Node.js 18+ 和 Git 环境。

04 · PROXY LAYER

CCSwitch 配置

保留平台切换，请求地址继续用 https://yjxapi.top/v1。

~/.codex/config.toml
CCSWITCH MACOS / LINUX 
model_provider = "OpenAI"
model = "gpt-5.4"
review_model = "gpt-5.4"
model_reasoning_effort = "xhigh"
disable_response_storage = true
network_access = "enabled"
windows_wsl_setup_acknowledged = true
model_context_window = 1000000
model_auto_compact_token_limit = 900000

[model_providers.OpenAI]
name = "OpenAI"
base_url = "https://yjxapi.top/v1"
wire_api = "responses"
requires_openai_auth = true
~/.codex/auth.json
